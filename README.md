## Что это за зверь такой?

У нас тут простенькая штука для отслеживания движения вокруг курсора. Хочешь, чтобы твоя поняшка глядела на всех вокруг, когда рядом кто-то шастает? Значит тебе сюда, присаживайся поудобнее.

Основная фишка в том, что программа берёт кусок экрана вокруг курсора и начинает там выискивать движение. Как только что-то нашла - сразу жмёт на циферки нампада (управление понитауна), чтобы твой персонаж глазел в нужную сторону. А если долго ничего не происходит, возвращает всё в исходное положение, чтобы глаза не иссохли. Это, конечно, используется для сидячих особей, чтобы сидя на одном месте смотреть на всех вокруг.

## Как этим добром пользоваться?

### Подготовка
Для начала тебе нужно поставить несколько библиотек. Открывай свою консольку и вбивай:
```python
pip install opencv-python mss numpy pyautogui pynput win32gui psutil
```

### Запуск
1. Запускаем через цмдшечку старую добрую (да, всё остальное я не приемлю)
2. Наводишь курсор на своего перса
3. Жмёшь 'D' чтобы вся эта механика завертелась
4. Наблюдаешь, как твоя поняшка превращается в самого внимательного наблюдателя на районе

### Кнопки управления
Тут у нас три волшебные кнопки:
- 'R' - Включить/выключить слежку
- 'D' - Врубить режим отладки (для тех, кто хочет посмотреть на внутренности) P.S. - работает только при активном окне cmd
- 'Q' - Закрыть программу

## Как оно работает внутри

Вся эта механика крутится вокруг простой идеи: берём квадратик 400 на 400 пикселей вокруг курсора и начинаем там шаманить с помощью OpenCV. Используем для этого хитрый алгоритм вычитания фона - типа как камера слежения, только покруче.

### Режим отладки
Если вдруг захочешь посмотреть, что там происходит под капотом (вдруг интересно, я не осуждаю), жми 'D'. Программа начнёт складывать картинки в папочку debug_images:
- original_*.png - че мы собственно видим
- fgmask_*.png - где движение нашли
- detection_*.png - где именно оно происходит

### Система направлений
```
7 8 9
4 5 6  <- numpad
1 2 3
```
Это у нас карта того, куда может смотреть персонаж. Просто как на циферках на клаве - 5 это прямо, 8 вверх, и так далее. Ничего сложного, но работает как часы.

## Настройка под себя

Хочешь подкрутить чувствительность? Вот тебе самые сочные параметры:
```python
self.movement_threshold = 500  # Насколько заметным должно быть движение
self.reset_position_interval = 3  # Как часто возвращаться в центр
size = 400  # Размер зоны слежения
x_threshold = 20  # Когда начинать поворачивать по горизонтали
y_threshold = 15  # Когда начинать поворачивать по вертикали
```

## Если что-то пошло не так

1. "Глаза дёргаются как у припадочного"
   - Подкрути movement_threshold повыше
   - Или уменьши размер зоны (size)

2. "Не реагирует, пони афк"
   - Уменьши movement_threshold
   - Проверь, может на паузе стоит

3. "Вроде глазеет, но не так часто/слишком часто"
   - Поиграйся с reset_position_interval
